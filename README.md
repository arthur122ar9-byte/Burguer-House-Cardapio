🍔 Burger House

Um cardápio digital moderno e responsivo para restaurantes, desenvolvido com HTML, CSS e JavaScript.

O projeto simula a experiência de um cliente realizando um pedido online, desde a escolha dos produtos até a finalização do pedido pelo WhatsApp.

📌 Sobre o projeto

O Burger House foi desenvolvido como um projeto de portfólio com o objetivo de criar uma experiência de cardápio digital completa, moderna e intuitiva.

O usuário pode navegar pelas categorias, pesquisar produtos, visualizar detalhes, personalizar o pedido, adicionar itens ao carrinho e finalizar a compra através do WhatsApp.

🛒 Como funciona
1. Escolha o produto

O cliente pode navegar pelo cardápio ou utilizar a pesquisa para encontrar um produto.

2. Personalize

Ao selecionar um produto, é possível escolher:

Quantidade

Adicionais

Observações

3. Carrinho

Os produtos selecionados são adicionados ao carrinho, onde o cliente pode alterar as quantidades ou limpar o pedido.

4. Checkout

Antes de finalizar, o cliente informa seus dados, endereço, forma de pagamento e outras informações necessárias.

5. WhatsApp

Após finalizar, o sistema cria automaticamente uma mensagem organizada com todos os dados do pedido e abre o WhatsApp para envio ao restaurante.
